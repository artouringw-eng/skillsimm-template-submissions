# D3 — Security Architecture & Engineering

- **Bell-LaPadula = confidentiality:** no read up (simple), no write down (*-property). Memory hook: "secrets don't leak down."
- **Biba = integrity:** no read down, no write up, the reverse of BLP. Memory hook: "don't get dirtied from below."
- **Digital signature:** sign with the sender's **private** key; verify with the sender's **public** key. Encrypt for confidentiality with the **recipient's public** key.
